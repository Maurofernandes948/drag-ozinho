# drag-ozinho

Fortune Dragon — jogo de slot em Angola. 10 rodadas grátis, multiplicadores até 2500x e levantamento por IBAN ou Multicaixa Express.

## Como correr

```bash
npm install
npm run dev
```

Produção:

```bash
npm run build
npm run preview
```

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS
- Framer Motion
- react-router-dom
